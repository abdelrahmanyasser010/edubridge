# EduBridge Backend

هذا المستودع هو Backend موحد للوحة التحكم وتطبيق المعلم وتطبيق ولي الأمر/الطالب.

## ابدأ من هنا

المرجع المعتمد للتنفيذ هو [الخطة الرئيسية](00_MASTER_PLAN.md)، ثم يقرأ المنفذ الوثيقة المرتبطة بالتاسك فقط:

1. [المعمارية](01_ARCHITECTURE.md)
2. [معايير الهندسة](02_ENGINEERING_STANDARDS.md)
3. [المجالات ونموذج البيانات](03_DOMAIN_AND_DATA.md)
4. [عقد الـ API](04_API_CONTRACT.md)
5. [الأمان والتشغيل](05_SECURITY_OPERATIONS.md)
6. [خطة التاسكات](06_AGENT_TASKS.md)

ملفات المواصفات الأربعة الموجودة داخل `docs/` هي **مدخلات تحليل ومرجع للمتطلبات فقط** وليست مصدر حقيقة للتنفيذ؛ عند التعارض تكون الوثائق المعتمدة وملف OpenAPI المستقبلي هما المرجعان.
