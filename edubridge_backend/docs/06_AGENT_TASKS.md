# خطة التنفيذ وتاسكات الـAgent

الحالات المسموحة: `TODO | IN_PROGRESS | BLOCKED | DONE`.  
قاعدة: Task واحدة `IN_PROGRESS` لكل Agent، ولا يصبح أي Task `DONE` بلا Evidence.

## طريقة تنفيذ أي Task

1. اقرأ الهدف والاعتماديات والوثائق المشار إليها.
2. افحص الكود الحالي ولا تفترض أنه مطابق للخطة.
3. اكتب/حدّث OpenAPI واختبارات القبول أولًا أو مع التنفيذ.
4. نفذ أصغر vertical slice مكتمل.
5. شغل quality gates ذات الصلة.
6. حدّث صف التاسك: الحالة، Evidence، وأي ADR.

قالب Evidence: `tests: <command/result>; schema: <migration>; contract: <path>; notes: <risk/none>`.
