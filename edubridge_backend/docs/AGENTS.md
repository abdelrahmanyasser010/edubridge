# EduBridge Agent Rules

اقرأ `docs/00_MASTER_PLAN.md` ثم التاسك المحدد في `docs/06_AGENT_TASKS.md` قبل أي تعديل.

## قواعد إلزامية

- نفّذ Task ID واحدًا فقط في كل مرة، ولا تبدأ تابعًا قبل اكتمال اعتمادياته.
- لا تخترع endpoint أو جدولًا أو enum. ارجع إلى `docs/` وملف OpenAPI، وسجل قرارًا جديدًا في `docs/decisions/` عند غياب قرار مؤثر.
- لا تعدّل migration منشورة؛ أنشئ migration تصحيحية جديدة.
- Controller رفيع: `FormRequest -> Action -> Resource`. لا توضع قواعد العمل في Controller أو Resource أو Model observer مخفي.
- كل وصول إلى مورد يمر عبر Policy، وكل عملية تخص مدرسة يجب أن تعمل داخل `TenantContext` وقاعدة بيانات المدرسة النشطة فقط؛ يمنع أي cross-tenant query.
- العمليات المالية والحضور الجماعي ونشر الدرجات تستخدم transaction وidempotency عند قابلية إعادة الطلب.
- الإشعارات والمهام الخارجية تعمل بعد نجاح commit ومن خلال queue.
- لا تعتبر التاسك منتهيًا من دون اختبارات القبول المذكورة، وتشغيل formatter والتحليل الساكن والاختبارات ذات الصلة.
- لا توسع نطاق التاسك لإعادة هيكلة وحدات أخرى. سجل المطلوب كتاسك لاحق.
- لا تحفظ أسرارًا أو بيانات طلاب حقيقية في Git أو logs أو fixtures.

## قبل تسليم أي Task

حدّث حالة التاسك ودليل التحقق في `docs/06_AGENT_TASKS.md`، ثم اذكر: الملفات المتغيرة، migrations، الاختبارات، وأي قرار أو مخاطرة باقية.
